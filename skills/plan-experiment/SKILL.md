# 规划实验

先查 [当前焦点](../../../project_memory/01_current_focus.md) 和 [台账](../../../project_memory/knowledge/12_experiment_ledger.md) 的相关索引/实验。仅在需要时补读决策、runbook、问题或文献条目。

## 形成可执行的比较

- 明确主要假设，以及结果会支持哪个下一步决策。历史失败只在相同适用条件下构成反证。
- 列出改动变量与固定项：数据范围/split、输入、初始化、代码/配置身份、训练预算、评价协议与可视化。
- 默认控制关键变量；若研究交互作用，可设计明确的多因素对照，说明如何区分各因素贡献。
- 指定 baseline 与 checkpoint 选择规则；测试集不用于调参或选 checkpoint。区分功能验证、子集筛选、完整验证和最终测试。
- 明确主指标、重要退化项和有效幅度；收益接近波动时，按需要安排配对样本、重复种子或不确定性检查，不给所有小实验强加重复次数。
- 给出先小后大的执行顺序、GPU/RAM/磁盘/时长预算、停止或扩展条件；未知资源成本先通过最小验证估计。
- 评价代码、split、metric 和协议按项目受保护资产处理，必要变更单独解释和验证。

## 输出与边界

交付假设、最小比较、保持不变的条件、判断标准、预算和停止条件；字段按任务需要组织，不要求长模板。
“方案可行”不等于“已获运行授权”。已经授权的实验可在既定范围继续，不重复确认。
