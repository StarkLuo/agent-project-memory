# 接手项目

## 恢复必要上下文

先读 [项目概览](../../../project_memory/00_project_brief.md) 和 [当前焦点](../../../project_memory/01_current_focus.md)。已有本轮有效上下文时不重复读取。
涉及实现或入口定位，再读 [仓库地图](../../../project_memory/02_repo_map.md)；其他知识先查索引、标题和相关条目，证据不足才扩展，不默认读 archive。

## 按接手对象核对事实

- 开发任务：确认实际仓库、分支、相关 diff 与未跟踪文件。用户改动不得覆盖；跨机器只迁移 HEAD 可能遗漏实现。
- 实验任务：根据 run id 找到对应主机、命令、日志、checkpoint 和完成标记。memory 中的“运行中”是上次观察，接手前重新核对；未连接远端时明确未核实。
- 续训任务：核对代码/配置/数据身份与恢复条件。发现已完成、仍在运行、产物缺失或身份不匹配时，分别处理，不自动重复启动、从头重跑或删除目录。
- 事实冲突：用户最新确认决定目标与授权；代码、配置和运行产物说明实际状态。不能用实现现状替代设计目标，也不能仅凭文档日期判定真伪。

## 交接结果

明确当前目标、已确认状态、仍待核实事项和下一步最小动作，然后继续已授权任务。已有授权在原任务与资源边界内有效；只对影响目标、接口、协议或显著成本的缺失选择提问。
