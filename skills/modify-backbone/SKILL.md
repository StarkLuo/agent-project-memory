# 修改主特征链路

先读 [仓库地图](../../../project_memory/02_repo_map.md) 与 [架构知识](../../../project_memory/knowledge/10_architecture_patterns.md) 中涉及的条目，再定位真实入口和调用者。论文驱动修改或路线冲突时补查相关文献、决策和实验，不全量读取。

## 修改前明确边界

说明本次目标、修改层级、上下游影响与最小验证。以下按改动选择：
- 数据/接口：shape、dtype、device、时间与坐标语义、配置注入和默认行为。
- 可训练路径：梯度是否到达预期分支，冻结参数是否保持不变，detach/no_grad 是否改变学习问题。
- 递归/渲染状态：跨轮读写、状态持久性、反传与场景重建顺序、重计算是否读取了已改变的状态。
- 保存/恢复：参数形状、架构字段、checkpoint 身份和兼容策略；不静默忽略不匹配参数或随机补齐。
- 训练/推理：可用输入、模式、监督信息边界及资源开销；测试时不能引入只在训练可得的信号。

项目特有不变量从架构和运行手册读取，不把其他工程的固定维度、预算或权重冻结方案照搬为本项目要求。

## 实现与验证

保持已约定接口和受保护评价资产；确需改变时说明原因及单独验证方法。保留用户工作区改动。
使用已有最小入口验证受到影响的不变量；普通改动不要求完整训练或所有分支审计。
交付修改理由、影响范围、相关验证证据和未验证风险。结构能够运行不等于研究假设成立。
